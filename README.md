
# Student Management System

## About the Project

This is a web-based Student Management System developed as a college programming project using C# and ASP.NET MVC.

The application is designed to organize and manage student information through a structured web interface.

## Technologies Used

- C#
- ASP.NET MVC
- SQL Server
- HTML
- CSS
- JavaScript
- Visual Studio Community

## Project Features

- Student management
- Display student records
- Add student information
- Edit student information
- Organized MVC architecture using Models, Views and Controllers

## Project Structure

- **Models:** Represents application data.
- **Views:** Displays the user interface.
- **Controllers:** Handles application requests and operations.
